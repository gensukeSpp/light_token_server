AGENTS.md への反映が完了しました。Issue #9 の変更内容に合わせて Milestones セクションを更新しました。

変更内容の反映点

Table schema
- guidline_end_date → guideline_end_date(スペル修正済み・Issue #9 と明記)
- accomplished_date の説明を「入力=close」→「入力=waiting 遷移」に更新

Semantic rules(状態遷移の実態に合わせて刷新)
- status="closed" は本実装では /milestone/remove のみ生成、waiting が再 open 猶予期間
- accomplished_date 設定時は closed ではなく waiting へ遷移し、子イベント completed=True を更新(close 相当)
- waiting から re-open 可: update で accomplished_date: null 明示 → open へ戻る(イベント completed は非破壊)
- closed への再 update は 409。本 Issue では閉じ確定はデータ上生成しない → re-open は waiting 由来のみ

API endpoints(契約の実態に一致)
- GET /milestone/all — open + waiting(status != "closed")を返す
- POST /milestone/update/{id} — admin・部分更新(title?/description?/guideline_end_date?/accomplished_date?)。accomplished_date 値=waiting、明示 null=re-open
- DELETE /milestone/remove/{id} — 削除ではなく closed 化して {"closed": id} を返す、と明記

変更していない箇所
- Permission model(admin のみ操作, 全 admin ユーザー)、Color rules、UI conventions は今回の変更の影響外のためそのままです。
